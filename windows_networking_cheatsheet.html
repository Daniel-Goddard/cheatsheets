ip

IP Configuration

ipconfig
View & Manage IP Settings
ipconfigShow basic network configuration for all adapters
ipconfig /allShow detailed network info, including MAC address and DNS servers
ipconfig /releaseRelease the current DHCP-assigned IP address
ipconfig /renewRequest a new IP address from the DHCP server
ipconfig /flushdnsClear the local DNS resolver cache
ipconfig /displaydnsDisplay the contents of the DNS resolver cache
rt

Reachability

ping · tracert · pathping
Testing Connectivity
ping <destination>Test whether a host is reachable and measure round-trip time
tracert <destination>Show the network path (hops) taken to reach a destination
pathping <destination>Combine ping and tracert for detailed per-hop path analysis
nt

Connections & Ports

netstat
Inspecting Active Connections
netstatShow active network connections and listening ports
netstat -aShow all connections and listening ports
netstat -nShow addresses and ports in numerical form, without resolving names
netstat -oShow the process ID (PID) owning each connection
netstat -anoShow all connections with numerical addresses and process IDs
dn

DNS & Network Shares

nslookup · net use · net view
DNS Lookups
nslookupQuery DNS information for a domain
nslookup -type=<type> <domain>Query a specific DNS record type, e.g. MX or TXT
Network Shares
net useManage connections to shared network resources
net viewShow computers and shares available on the network
net view \\<computer>Show the shared resources on a specific computer
ar

ARP & Routing

arp · route · nbtstat
ARP Cache
arp -aShow the ARP cache, mapping IP addresses to MAC addresses
arp -d <IP>Delete an entry from the ARP cache
arp -s <IP> <MAC>Add a static ARP entry
Routing & NetBIOS
route printShow the local IP routing table
nbtstat -nShow local NetBIOS names
nbtstat -a <remote>Show NetBIOS names registered on a remote computer
nbtstat -cShow the local NetBIOS name cache
rm

Identity & Remote Access

hostname · ssh · rdp
Machine Identity
hostnameShow the local computer's name
getmacShow the MAC addresses of network adapters
Remote Connections
telnet <host> <port>Open a basic, unencrypted remote connection to a host/port
ssh <user>@<host> -p <port>Open a secure, encrypted remote shell connection
mstscOpen Remote Desktop Connection
